Setup Guide

  1. Create and activate the virtual environment.
  2. Install dependencies with pip install -r requirements.txt.
  3. Run python manage.py makemigrations and python manage.py migrate.
  4. Start Redis (redis-server or Docker).
  5. Launch the dev server with python manage.py runserver.

Use setup.sh for an automated flow.

API Reference

Base URL: /api/
Endpoint Method Description
/api/employees/ GET/POST List or create employees.
/api/attendance-records/ GET Historical recognition events (supports ?search=<name>).
/api/attendance-records/recent/ GET Latest 20 recognition logs.
/api/daily-attendance/ GET Aggregated daily attendance.
/api/camera-config/ GET/POST/PATCH Manage camera settings and sync with camera_config.json.

All endpoints require authentication (session or basic auth).

UI Usage Guide

  • Dashboard: Monitor real-time stats, live recognition log, and charts.
  • Employees: Manage employee profiles, edit details, and view attendance history.
  • Register: Capture webcam photo, preview, and save embeddings.
  • Recognition: Stream live video, visualize detections, and track daily summary.
  • Attendance: Filter records by date/department and export CSV.
  • Camera Settings: Tweak device, resolution, FPS, brightness, contrast, and sharpness.

Deployment Checklist

  • Set DEBUG=False and configure ALLOWED_HOSTS.
  • Switch DATABASE_URL to PostgreSQL or MySQL.
  • Run python manage.py collectstatic and serve static files via CDN/web server.
  • Use Daphne or Uvicorn with ASGI for Channels/WebSockets.
  • Secure Redis and configure persistent storage for media.
  • Configure HTTPS (nginx/Apache) and environment secrets.

Refer to the README for extended setup and troubleshooting tips.
